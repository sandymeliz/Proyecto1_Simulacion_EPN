## Estructura
| Archivo | Contenido |
|---|---|
| `app.R` | Ensambla las 5 pestañas (navbarPage) |
| `R/mod_p1_pseudoaleatorios.R` | MCL, Lehmer, Cuadrados Medios |
| `R/mod_p2_montecarlo.R` | Integración por Montecarlo |
| `R/mod_p3_discretas.R` | Binomial, Poisson, Geométrica, personalizada |
| `R/mod_p4_continuas.R` | Uniforme, Exponencial, Normal, personalizada |
| `R/mod_p5_bondad_ajuste.R` | Kolmogorov-Smirnov y Prueba de Rachas |
